# Art. 18 Ersatzwahlen
1 Wird nach der Erneuerungswahl ein Amt frei, so ist eine Ersatzwahl anzuordnen.
2 Das zuständige Departement ordnet die kantonalen Ersatzwahlen, der Rat die Ersatzwahlen von Gemeindebehörden an.
3 Wird innert sechs Monaten eine Erneuerungswahl durchgeführt, so kann die Ersatzwahl unterbleiben, wenn nicht wichtige, unaufschiebbare Geschäfte sie erfordern.
